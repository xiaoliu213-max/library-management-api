# 2026-10-26

## 前端封面排版 + 材质两处修复（frontend/js/books.js、environment.js）

- **书名排版**：`drawCover` 改为固定版面分区 `LAYOUT`（印记条 0..56 / 书名区 74..306 / 作者栏 342）。
  - ≤8 字且不含拉丁词 → 竖排，字号由「书名区高度 ÷ 字数」倒推，整块垂直居中，永远不会顶到印记。
  - >8 字或含连续 2+ 拉丁字母数字（HTTP、3D）→ 横排；用 `tokenize`（拉丁词不折断、行首标点粘前词）+ `balanceLines`（枚举断点取最宽行最窄）分行，2 行（>18 字 3 行），字号由最宽一行反推。
  - 类别印记独占顶部暗色条（下沿金线分隔），类别/作者名超宽自动缩字号。
- **封面材质**：`MeshStandardMaterial` + emissive → `MeshBasicMaterial({map})`，封面完全不参与光照，颜色即所绘；书脊/纸页仍保留 PBR。
- **光链光珠**：`environment.js` 里按相机距离淡出 `clamp((d-0.8)/1.8)`，贴脸不再糊屏。
- 模块缓存版本号 `?v=3` → `?v=4`（index.html / main.js / ui.js）。
