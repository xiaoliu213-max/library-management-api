# 灵书阁 · 3D 前端

「my_first_api」图书管理后端的玄幻风 3D 界面。**与后端代码完全分离**——唯一的接入点是
`vibe_server.py`，它只是 import 现有的 `main.app` 并把本目录挂载为静态文件，不修改后端任何一行。

## 启动

```bash
.venv/Scripts/python.exe vibe_server.py
# 浏览器打开 http://127.0.0.1:8080 （8000 端口被占用，固定用 8080）
```

## 功能

- **双阶段场景**：未登录停在「玄关」——竖立的传送门法阵 + 环绕符文 + 绯紫光核，登录/注册面板居中放大；登录或注册成功后金光一闪，"飞入"藏书阁；断开灵契再闪回玄关。玄关机位固定（可手动拖转），题字带粒子流与点击波浪
- **环形书库**：典籍立在内壁书架上围成一圈（44 列 × 5 层 = 单页 220 卷），同类相邻形成色带；超过 220 卷自动分页（底部 ‹ 上层 / 下层 ›），几千卷也只是多翻几页
- 书库内滚轮是**视向行走**：朝你注视的方向推进/后退，可以一直凑到书墙跟前；**视角俯仰无上限**（可仰视高层书架，相机有离地保护），双击空地回到全景；玄关阶段滚轮仍是常规轨道缩放。两阶段背景均固定机位 + 手动拖转
- 3D 场景：星云 / 星空 / 灵气尘埃 / 地面法阵（Three.js + UnrealBloom 泛光），环境层含盘龙柱、柱廊、光链、石碑、天环、花瓣、云雾、浮岛、光蝶
- 点击典籍 → 相机推近 + 古卷详情（真封面 / 属性 / 符印 / 译笔 / 借阅符契）
- 真实封面：详情面板优先显示 `covers/{书名}.jpg`，没有就退回自动生成的玄幻封面
- 检索法阵：关键词（书名/作者模糊搜索）、类别筛选、排序——全部走后端 `GET /v1/books` 的查询参数；筛选时自动回到第一页
- 缔结灵契（JWT 登录）/ 录入道籍（注册，成功自动登录）
- 借阅（可写借阅寄语，落库到 `note` 字段）/ 归还 / 焚毁（管理员，两段点击确认）
- 召唤典籍（新增书目）、ESC 逐层关闭面板、401 自动退出登录态

## 目录

```
frontend/
├── index.html        # 页面骨架 + importmap
├── css/style.css     # 全部样式（金/暗紫玄幻主题）
├── js/
│   ├── api.js        # /v1 接口唯一出入口（token、错误格式解析）
│   ├── scene.js      # 场景/灯光/星空/法阵/玄关传送门/相机飞行/泛光
│   ├── environment.js# 环境层：地台/盘龙柱/柱廊/光链/石碑/天环/花瓣/云雾/浮岛/灵波/光蝶
│   ├── gate-title.js # 玄关题字：粒子流 + 鼠标浮起 + 点击波浪
│   ├── books.js      # 封面绘制、悬浮典籍、拾取与排布
│   ├── ui.js         # 界面层（面板、表单、提示）
│   └── main.js       # 主控：把以上全部串起来
├── vendor/           # Three.js 0.160 + 插件（本地化，不依赖外网）
└── covers/           # 真实封面图，命名 = {书名}.jpg
```

## 怎么补封面

往 `covers/` 里放一张 `{书名}.jpg`（书名和数据库里完全一致，如 `流浪地球.jpg`）即可，
刷新页面生效。当前有真封面的书：三体 / 三体Ⅱ·黑暗森林 / 红楼梦 / 白夜行 / 盗墓笔记 /
解忧杂货店 / 哈利·波特与魔法石（豆瓣按书名抓取，其余几本被反爬占位图拦住了）。

## 可调参数

- 每层书阵本数：`books.js` 里 `PER_ROW = 5`
- 全景机位：`scene.js` 里 `OVERVIEW`
- 泛光强度：`scene.js` 里 `UnrealBloomPass(..., 0.85, 0.55, 0.18)`
